# World outlines

Source: Natural Earth, 1:110m admin-0 countries, 177 features.
Downloaded 2026-10-03 from the official project maintainer repository:
https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_admin_0_countries.geojson

Public-domain terms: https://www.naturalearthdata.com/about/terms-of-use/

Geometry is an overview dataset, not street-level mapping. Map units and names follow the source dataset. This application does not infer patient locations, disease prevalence, care availability, or trial sites from country polygons. Data is bundled locally; no map provider or geolocation permission is required.
